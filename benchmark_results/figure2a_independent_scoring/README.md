# Figure 2a

Independent scoring throughput starting from preencoded k-mers.

Synthetic 300 Mb and GRCh38.p14 chr1; k = 16, 19, 21, 24, 31. Five technical observations per condition.

`figure2a_raw.csv` and `figure2a_summary.csv` are historical measurements and include additional recorded methods; the manuscript panel uses five. `figure2a_plot_data_path_redacted.tsv` removes path-only columns; values and rows are retained. `Figure2_manuscript.png` is the exact combined Figure 2 image from the manuscript.

These are saved historical results, not a new performance run. The experiment-specific reproduction materials and validation limitations are documented in `reproducibility/figure2a_independent_scoring/` when available; see the [results index](../README.md) and [dataset guide](../../docs/datasets.md).
