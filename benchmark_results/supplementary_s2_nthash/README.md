# Supplementary section S2 and Tables S3–S4

Continuous-DNA ntHash comparison and a separate LTO sensitivity experiment.

Two inputs; k = 15, 19, 21, 24, 31; w = 5, 10, 20, 50. Five paired technical repetitions within a process.

`primary/` contains the original 40-condition S3 records; `lto/` contains the separate OFF/ON S4 records. The LTO raw table removes path-only fields and is a derived historical copy, not a newly executed grid.

These are saved historical results, not a new performance run. The experiment-specific reproduction materials and validation limitations are documented in `reproducibility/supplementary_s2_nthash/` when available; see the [results index](../README.md) and [dataset guide](../../docs/datasets.md).
