# Supplementary section S3.5 and Table S9

Controlled seed-supported placements in AluSx and AluJb.

Recorded 150-base reads; k = 21, w = 20; eight timing cycles with four sweeps per cycle.

`kernel_timings.csv` and `kernel_timing_summary.csv` contain saved timing records and aggregates. The additional comparison and workload CSVs contain aggregate candidate counts, accuracy and paired comparisons without per-read positions. Alternative locations exclude the exact known source locus, not every start within its source interval. Candidate traces cover only selected origins, not all candidate positions. Reference-derived reads and per-read coordinates are not distributed here.

These are saved historical results, not a new performance run. The experiment-specific reproduction materials and validation limitations are documented in `reproducibility/supplementary_s3_5_alu/` when available; see the [results index](../README.md) and [dataset guide](../../docs/datasets.md).
