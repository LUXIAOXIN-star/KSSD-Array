# Supplementary section S1.2 and Table S2

Independent scoring of KSSD, XXH3 and gxhash.

Two inputs; k = 16, 19, 21, 24, 31; five independent processes per condition.

`gxhash_raw_path_tokenized.tsv` retains all 150 measured rows, and `gxhash_warmup_path_tokenized.tsv` retains all 30 warmups separately; both replace machine path prefixes and are derived copies. Warmups are not included in formal summaries. `gxhash_summary.tsv` is the saved historical summary. This run is independent from Figure 2a.

These are saved historical results, not a new performance run. The experiment-specific reproduction materials and validation limitations are documented in `reproducibility/supplementary_s1_2_gxhash/` when available; see the [results index](../README.md) and [dataset guide](../../docs/datasets.md).
