# Figure 1

Worked 19-mer scoring example with balanced 7/6/6-nucleotide segments.

The fixed example in the manuscript uses cap 8, SplitMix64 seed 42 and a 38-bit score.

`Figure1_manuscript.png` is extracted byte-for-byte from the manuscript. `Figure1_manuscript.drawio` is extracted from its embedded editable metadata; XML parsing passed but opening and rendering in diagrams.net were not verified. The original table-generation workflow is not established.

These are saved historical results, not a new performance run. The experiment-specific reproduction materials and validation limitations are documented in `reproducibility/figure1_algorithm/` when available; see the [results index](../README.md) and [dataset guide](../../docs/datasets.md).
