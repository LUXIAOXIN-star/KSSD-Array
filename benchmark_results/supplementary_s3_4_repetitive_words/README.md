# Supplementary section S3.4 and Table S8

High-copy word selection in mixed windows.

Yeast S288C and Arabidopsis TAIR10.1 nuclear sequences; k = 21, w = 20.

`fixed_per_record.csv` contains reference-derived per-record counts; the two
summary files contain aggregate statistics. They do not contain reference DNA
sequences. Exact reference FASTA files remain external. No standalone counting
program is distributed here, so these saved records are not a complete
source-code reproduction package.

These are saved historical results, not a new performance run. The experiment-specific reproduction materials and validation limitations are documented in `reproducibility/supplementary_s3_4_repetitive_words/` when available; see the [results index](../README.md) and [dataset guide](../../docs/datasets.md).
