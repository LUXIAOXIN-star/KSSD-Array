# Controlled Alu localization and seed workload

## Manuscript reference

Supplementary Section S3.5 and Table S9. [Results](../../benchmark_results/supplementary_s3_5_alu/README.md).

## Experimental objective

Controlled Alu localization and seed workload.

## Required inputs

Reference-derived UCSC hg38 chr21/chr22 queries and matching reference
sequences. The recorded chromosome inputs were [chr21](https://hgdownload.soe.ucsc.edu/goldenPath/hg38/chromosomes/chr21.fa.gz)
and [chr22](https://hgdownload.soe.ucsc.edu/goldenPath/hg38/chromosomes/chr22.fa.gz).
The recorded compressed-file SHA-256 values are respectively
`c979ca1e5065c2521a50773473e0d0cc018fd6f3e9bb3aa90493fe7b45d57d1b` and
`05f9d97d6fbfd08a44ca45b50837ca2ae9c471f35ba79dffec04d2cb5eaaf695`.
Exact RepeatMasker annotation snapshots, earlier exclusion coordinates,
selected-origin coordinates and query records are also needed but are not
distributed here. See the [dataset guide](../../docs/datasets.md).

## Input preparation

Queries derive from centered 150-base intervals within RepeatMasker AluSx and
AluJb annotations. Selection uses chr21 and chr22, excludes overlaps with the
prior source set, and applies within-cohort nonoverlap; coordinates are
zero-based and half-open. The exact selected origin and query files were
generated by historical scripts that are not distributed in this package.
The complete historical query TSV has SHA-256
`7c2caec131ac29901452210737933cac7a9f5fb94b63337264d2c3dc5a7a9faa`;
the Table S9 subset contains 3,349 AluSx and 2,929 AluJb unmutated,
forward-strand reads. These checksums are identifiers, not download links.
The historical generator and coordinate records are necessary for an exact
reconstruction; their availability and redistribution conditions have not
been established for this public collection.

## Parameters

k=21, w=20, four methods and two frequency policies. Table S9 uses
`unfiltered`; `copycap1000` is a separate filtered control. The Table S9
reads are 150 bp with zero substitutions.
