# Supplementary Table S2 alignment consistency

This Phase 5C workflow reproduces downstream alignment-consistency deltas for
Human GRCh38.p14 and Zea mays B73 RefGen_v5 at 100 bp and 150 bp. It compares
Original Minimap2 with KSSD-Array only. Phase 5B indexing performance is a
separate workflow; alignment runtime is not a Table S2 metric or acceptance
criterion here.

## Historical reads and commands

The exact historical single-end FASTQ files are pinned by size, SHA256, and
actual read count in `reproducibility/minimap2/alignment_consistency/config.json`. They
were generated by ART_Illumina Q 2.5.8 with the built-in HS25 empirical error
and quality profile, seed 42, and the coverage values preserved in each
condition's simulation command. The existing files are used directly and are
not regenerated.

Each read set is aligned once per method with:

```text
minimap2 -ax sr -t 1 COMPATIBLE_INDEX READS | samtools sort -o OUTPUT.bam -
```

The original executable uses a standard `MMI2` index; the integrated
executable uses its Phase 5A `KSA1` index. Repetitive alignments are selected
with `bedtools intersect -a BAM -b BED -u`. All references, reads, truth
tables, repeat BEDs, indexes, BAMs, logs, and formal CSV outputs stay outside
Git.

## Metrics and Table S2

Primary mapped records use the historical `samtools view -F 2308` definition.
Mapping correctness requires the truth target and a position within 5 bp of
the historical forward or reverse-offset truth coordinate. Global accuracy,
repetitive-region accuracy, and MAPQ=60 rate divide by truth-matched primary
mapped records. The Table S2 direction is KSSD-Array minus Original Minimap2,
multiplied by 100 to percentage points. CSV retains full precision; Markdown
reproduces the historical two-stage display rule (six-decimal proportion,
then signed three-decimal percentage with half-up rounding).

The historical workflow did not measure nucleotide alignment identity. The
raw identity field is explicitly named `truth_position_accuracy` and is the
global truth-based mapping accuracy. Raw rows also include unique mapped
queries, primary percentage, secondary/supplementary counts, output record
count, input/index/executable hashes, output BAM hash, and exact commands.

## Running

Run the fixture preflight with approved external Phase 5B artifacts:

```sh
make minimap2-alignment-preflight \
  PHASE5B_OUTPUT=/external/results/minimap2-indexing-s1 \
  MINIMAP2_ALIGNMENT_PREFLIGHT_DIR=/external/work/alignment-preflight
```

The preflight accepts freshly built executables from the pinned upstream
version and records their actual hashes, because compiler and linker metadata
can change a binary hash across clean hosts. Formal mode retains the configured
historical executable-hash checks.

Run the formal workflow only with explicit configuration and output paths:

```sh
KSSD_DATA_DIR=/path/to/data-root make minimap2-alignment-formal \
  PHASE5B_OUTPUT=/external/results/minimap2-indexing-s1 \
  DATA_CONFIG=reproducibility/minimap2/alignment_consistency/config.json \
  OUTPUT_DIR=/external/results/minimap2-alignment-s2
```

`KSSD_DATA_DIR` contains the configured `seq/...` paths. Repeated
`--reference`, `--reads`, `--truth`, and `--bed` arguments provide explicit
overrides. The formal output directory must not exist. Because Phase 5B kept
only the final per-dataset KSSD index, Phase 5C deterministically rebuilds one
original index for each of the two references and verifies it against the
Phase 5B recorded size and SHA256. No timing conclusion is drawn from this
preparation.

The output contains eight raw method-level rows, an eight-row metric table, a
four-row Table S2 CSV and Markdown preview, build/run manifests, logs,
alignments, the two rebuilt original indexes, and query-level diagnostic CSVs.
