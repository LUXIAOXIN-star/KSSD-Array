# Continuous-DNA ntHash comparison and segment-cap diagnostic

This directory is a navigation page for two separate historical experiments.
The former `phase3_adapter.py`, `build_local.py` and `run_benchmark.py` are not
distributed here; no commands using those files are provided.

- **ntHash comparison:** see the [portable workflow](../table2_nthash/README.md)
  and its [saved results](../../benchmark_results/table2_nthash/README.md).
  The small-input workflow was checked; the complete historical grid has not
  been replayed as part of this package.
- **Segment-cap sensitivity:** see the [C=4–8 source and limitations](../supplementary_s2_nthash/c_parameter_scan/README.md)
  and [saved diagnostic results](../../benchmark_results/c_segment_scan/README.md).
  A complete portable runner is not supplied; the diagnostic is not assigned
  a Supplementary Information table number.

The experiments have different timing boundaries and output definitions. See
each linked guide for inputs, parameters, dependencies and validation status.
